# Playground · PRIME design system

React practice for a shared-component role, plus mid-level React theory.

JavaScript and TypeScript drills stay on Boot.dev. This app is the React part: components, props, state, clicks, lists, and effects.

## Run

```bash
cd playground-prime-ds
npm install
npm run dev
```

Opens on port **5186**. Restart the dev server after pulling new drills.

## How to practice

1. Read the plan.
2. Open `drills/<id>/task.jsx` and write the component. Leave the test file alone.
3. In the React drills tab, press **Run tests**.
4. Use the theory tab to say each answer out loud, then do the check.

The lesson shows the tool on a small example. It is not the answer.
